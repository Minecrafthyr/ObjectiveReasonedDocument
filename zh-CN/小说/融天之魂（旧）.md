# 第1章 残躯

我是一个原生魂体，住在这片茂密的树林中。天空始终降下光芒，光线通过弥漫的魂雾洒向大地，每五个小时明暗交替一次，亮时为白昼，暗时为亮夜。（白昼的亮度大概是地球正午的两倍。亮夜的亮度相当于地球正午。）不见尽头的魂质从天上流淌而下，仿佛是不间断的雨幕，升得越高，魂雾越浓，天空带给我的危机感也越强。灵质仿佛永不枯竭从地下缓缓涌出，钻得越深，岩层就越坚硬。

我抛下手中扭动的蛇，前往树林中心。那是有片空地，地下几十米处正不断散发着和周围相比堪称炽烈的灵质和魂质，我不敢靠近，只能在周围吸收、摄取土壤中的力量。

突然，周围的魂质一阵波动。我连忙后退，感知中，魂质辐射突然增加，又逐渐降低。待到波动平复，我小心地将魂质探向地下，只摸到一个无法被魂质穿透的躯体，躯体正在缓慢碎裂、分离，最终固定为几十个散发灵质的玄奥碎块。它们似乎含有无数我无法解析的信息。灵质屏障逐渐消失，我探查到一个碎裂的核心。与那些碎块相反，核心上的裂纹正逐渐恢复。

短暂犹豫过后，我延伸魂体，拉取灵质核心，它从地下飞出，悬浮于我的下方。我尝试激活它，顿时周围灵质涌动，朝我这里涌来。我很高兴，将其收入体内，魂体直接接触核心之上，我感觉到它正不断微调整接触点，最终和我的魂体契合，我得以控制这个核心。灵质核心是那残躯存活时的灵质中枢，就叫灵枢好了。这个灵枢起到控制、调用灵质的作用，而灵质是可以近乎无限压缩且快速释放的物质。

数天后，我终于完全把那具残躯收为己用。这具躯体显然灵质枯竭，但即使如此也无比坚固，我向下挖掘，采集灵矿。一个念头下灵枢就使得各异的灵石灵质全无，也不知道这具躯体的上限在哪里。

因此，这具躯体也被我命名为“容灵残躯”。那么，我的魂体就叫“启灵之魂”，整体就叫“启灵”。

我的力量得到了飞跃，这片树林中已经没有能与我相比的生物，我决定离开这片刚刚被我命名为“初始之地”的树林。我选择向四周探索，和飞行相比，钻地实在太慢，这具灵躯虽强，但也限制了我在地下的行动。悬浮于空中，魂体散射状绽开，吸收空气中的魂质，壮大自身。同时，魂体触须延伸到高空，探查周围，捕获灵质辐射、魂质辐射、电磁辐射所产生的信息向我涌来。这个技巧叫被我称为“自由视角”。整理信息过后，我朝着灵质较为浓郁的方向前进。

借着空中浓郁的魂质加速，我以每秒八百米的速度移动，卷动高空的气流。日夜兼程，风雨无阻。在迷雾中总是出现一些奇特的生态域，比如被黑色藤蔓蔓延地面和天空的直径两千米的圆形区域，或能够发光和散播孢子的高蘑菇林，还有一些区域不自然的被浓雾覆盖。亮夜，我望向明亮的天空，那浓雾的背后还传来隐蔽的光线，我的感光器官经过多轮改进才发现它们，真想去看看那到底是什么，可惜从天空而来的压迫感使得我不敢向上探索。有时遇到几个飘在空中的透明魂球，那是些生物残魂，我总是直接将它们融入体内，这样就能读取出记忆残片；如果将它们吞噬，那就和吸收天空中的魂质没有太大区别。

# 第2章 探索者

这天，我正飞行于空中，自由视角渗入地下，我突然感到不对，缓缓停了下来。似乎有什么东西在聚拢周围的灵质，我将视角继续深入地底，最终在地下千米处发现了——灵质屏障。经过瞬间的思考后，我将魂质缓慢渗透入屏障内，开始观察周围。只见这是一个长宽八十米，高五米的空间，地下铺有法阵。其中有几间石室，石室顶部有未激活的灵质照明设备。这时，灯光全部亮起，某间石室的门缓缓打开，其中走出一个人类老者。粗略探查，他的魂质总量约为我的八分之一，而灵质总量约为不算上灵枢的我的四分之一。

在我面前站定，他用魂质传递简单的信息：“你是……？”

我凝聚出一个魂质球体，将大量信息刻在上面，其中有我使用的语言列表，以及我正在寻找智慧生命，准备进行交流或合作的期望。将魂质信息球交给他，我静待一旁，观察他的情绪起伏。老者一番研究之后，“启灵……你好”，“仔细想来，其实我也没有什么好隐瞒的，那么就让你的本体下来，直接用魂质交流吧。”灵质屏障被撤下，数秒过后，我的主体来到了地下一千米深处。我的魂体末端塑造出接口，开始与他交换信息。

天魂地灵世界中，资源充足。人类还处在部落时代，但是技术已经不亚于蒸汽时代。有灵质切割刀，灵质枪械等。数个部落共同抵御其他生物的侵扰，形成一个聚落。他诞生于其中某个部落中，名叫“开辟”，天资卓绝，与部落成员一同成长，最终不负众望，成为了聚落中的强者。他并没有就此止步，而是开始了长达数年的的功法学和阵法学研究。

某天，一只灵质生物隐匿在灵气潮汐造成的晨雾中，使用灵质之矢突然袭击一名部落长老，灵质穿过头颅、脑组织、魂体直透魂体，一击致命。其他部落长老收到传讯急忙赶来，拼着灵质耗尽使用阵法发动蓄力攻击，最终损坏对方灵质核心，才算除了这一大患。

当时他正在研究功法，直到二十分钟的周期结束之后，才惊觉异变，冲出地底，只见得部落长老正在调养疗伤，还有几具破损尸骸。

在时间的沉淀下，他的情绪化为了紧迫感，迫使他离开聚落周围，寻求机缘。他越过各种各样的森林，搜寻灵物，与妖兽战斗。其间数次折返，给族人带回资源。不过，人都有老去的时候，开辟也不例外。他已经活了二百六十多岁，全身上下已经被多处改造。然而，这次是大脑开始衰老了。虽然天魂地灵世界的人类大脑中都有空间放置魂核，使脑与魂核产生联动效应，加速思考，但使用魂核和只剩魂核还是很不同的。“如果我的身体死亡了，只剩魂灵体，那我还是我吗？”他这样想，思维逐渐清晰，“总之，‘我’的概念并不是固定的。研发一部稳定魂体灵魂意识的功法，才是关键。”他离开了聚落，选了块合适的地方，掘入千米深的地下，开辟了这个场地。就这样，通过数年的努力，他研发出稳定魂体意识的功法，并开始准备应对躯体腐朽之劫。

可是在今天，他有了一个更好的，大胆的方案：与我进行融合。他看着我说：“我从未见过像你这样，可以融合其他魂体的生物。”

我提醒他：“可是，我融合魂体时会抹消对方的意识，只保留记忆。”他有些兴奋，魂质连接微微波动：“只要在灵魂融合时，同时将稳定的意识进行融合，意识就能保存。我已经有了稳定灵魂的功法，只要稍加改进，就能达成与你灵魂融合的效果。那时，你能得到二百七十年的经验，而不是融合残魂后的记忆碎片，而我能获得数倍的魂质和灵质。这个提议如何？”我对这个提议很感兴趣，略作推演之后，我并没有察觉有什么不妥之处。“我觉得挺好。”

他将各式各样的装备和研究设备放进一个大袋子，并背在背上。我们回到了地面。看着那遮蔽视线的迷雾，他问我：“你就没有迷茫过吗？”我这样回答：“我没有敌人，也没有苦恼，身体也不会腐坏。我只是本能地追寻知识与力量。另外，我才诞生四十天，我的知识都是一路上从残魂中整理出的。”听着这样的话，他陷入了那深沉的回忆。

# 第3章 灵魂融合术

我正朝一个方向飞去，据开辟所说，那里有叫“分体生物”的智慧生物部落，他们正稳步向外扩张。开辟曾经见过他们的首领，当时那位首领要比他稍强，但并没有借助主场优势为难开辟，只是将其赶出了领地。我们正打算与他交流修炼经验，毕竟我们在灵质的理解上较弱。

开辟：“就在这里停下吧。距离目标还有四百千米。”

我问：“你已经研究出来能够融合灵魂的功法了吗？”

“是的，已经完成了。我已经在研究下个阶段的功法。”说完，他拿出袋子里的信息球，扔给了我。根据预留的翻译信息，我很快解析了全部内容。我高兴地魂质涌动：“那么开始吧！”随即开始绘制融合仪式所需法阵。“等等，我想让你给这个功法取个名字。”

我并有停下刻画法阵的动作：“灵魂融合术”。

随即开始在自己旁边的空气上刻画法阵，他刻画的速度明显比我慢。开辟感叹：“你这也太高效了。”

融合开始了，我和他之间被扰动的魂质与灵质自然地划分出界限。容灵残躯的玄奥结构散发光芒，周围已经被我们强化过的石壁都被灵魂场压出了凹陷。人类老者浑身赤裸的盘膝坐在我对面，魂雾和灵光将一切掩盖。气场虽弱于我，却也有岁月沉淀出的精妙。他的身体开始崩溃，裂口中迸发出明亮的光芒。灵与魂分别从中冲出，向我靠近，在法阵高速运行所产生的各种波动中与我轻柔地接触。我魂体的边缘不断塑造出无数接口，对接功法中规定的信息交换口。感官和记忆在这个过程中开始连通和共享。最终，视觉上只留下一个躯体。我和他开始交流：“半融合完成了？”

“完成了，现在就是半融合状态。”，开辟说，“我正在理解这个状态，应该很快就能掌握主动融合的技巧，到时候我们就能主动融合较为弱小的魂体了。”他看了一眼地上的灰烬，魂体都迟缓了一瞬，又看到了边上那仍然完好的袋子，又反应了过来，“启灵，我们开始研究更高效的信息交换吧。”。

随后我们就开始研究什么样的连接形态能进行高效的信息交换。

在进行了很多次优化后，我们都没有更好的方案了，于是我恢复了正常的信息交互：“话说你对于装备制造还有什么了解？刚才的测试中你传了一部分信息，我觉得很有意思。”毕竟我不需要武器，这具躯体就是一个我尚未完全掌握的玄奥兵器。但这并不代表我就不需要研究武器，或许能研究出进一步操作容灵残躯的方法呢？

他并未多言，直接将数据传给了我。我的魂体开始运转，理解并优化各种武器模型。

拂过一个个模型，与容灵残躯的特征进行比对……

差别太大，虽然有很多特征都近似，但精妙程度完全不在一个层次。不过这还是给了我很多灵感。


# 第4章 分体生物

我们再次上路，十几分钟后，我们来到了分体生物的领地旁边。升高视角，只见一片被清理出来的空地，一排间隔五十米，二十米高的瞭望塔矗立其上。继续升高视角，从高空俯视，瞭望塔圈起了领地。有趣的是，地表植被呈同心圆状分布，也就是从领地中心开始，有一圈空地，然后一圈植被，如此重复。

现在，我们的目的是获取最新信息，确保没有变故发生。我探出魂质触手，抓来数只分体生物。突然悬空引起了一阵挣扎，但我很快就将他们放了下来。

仔细打量这四肢着地的生物，他特殊的四肢允许他直立或爬行；仰面朝天却也能稍有阻滞地行动，然后再翻转回来，他们的格斗也常用翻倒断定胜负。实际上，这样特殊的构造是为了繁育后代。繁殖方式是两个分体生物后背紧贴，然后将其身体内部预留的空洞合并为子宫。所以分体生物的性别通常是“½雌体”。

“你们是外来的侵略者吗。”

“我们是来找你们的领主商量事情的。现在告诉我这里最近发生了什么。”我详细询问了这里的近况。并没有什么令人惊奇的消息，分体生物的种族稳步发展。

既然没有发现特别的变化，那就去找他们的领主吧。我们的思维同步已经很深，一同向目标而去。

石质结构的城镇就从迷雾中显现，这里整齐地矗立着颜色各异的石质房屋，处于中心的高大石殿表面粗糙，呈暗紫色，与周围建筑相隔二十几米。这里的生物们似乎都过得很自由，正常地工作或休息。

当我们距离中心镇外围六千米时，镇内警备力量开始调动，我们慢慢减速，最终在距离五千米处停下，那本地领主浮定来到我们的面前。我仔细观察他，实力并没有超出我的预料。

“你来此有何目的！”浮定如此问。

“我们是来交流经验的。”

“我们到那里谈吧。”浮定并没有放松警惕，而是随机挑选了一个方位，这样如果发生意外不容易波及周围。我们在一片林地上方开始交流信息。两方在空中站定，开辟这时候跳了出来。一感受到这熟悉的气息，浮定的情绪都出现了波动：“原来是你把他带过来的！”

“准确来说，这只是个凝聚有我特性的临时魂体。我和他现在是一体的。我们还是来交流一下感悟吧。”

在看到开辟后，他的态度明显转变，表示同意交流，于是我们开始交流修炼方面的经验。我们两方都花了一段时间整理信息。

令我有些惊讶的是，他获得了一个文明巡游使带来的魂质通讯技术。

我将我的灵魂融合技术分享了出去，经过推演，在制造魂质武器时可以融合多个功能，但也仅此而已。

……

交流完毕之后，我很快就告别离开，在附近随便选定一地休息。伴随魂体的最后的模块在体内贴合，和开辟的所有记忆和思维都连通了。“是时候重新取个名字了，就叫‘统灵’吧。”

我是统灵。启灵和开辟的统一之魂。向知识与力量前进！


# 第5章 深黑藤沼

告别浮定，我现在打算增强自己的实力，看前面的这片藤沼，我的目标是它的核心，它的核心拥有全套常见的灵质转换器。黑色的藤蔓和叶子覆盖了直径二平方千米的区域（这是因为它并没有领悟高效灵魂压缩方法）。它们正像波浪一样有规律地摇曳。其中心处的藤蔓高出地面几百米，越往外围越低。

这样大的生物确实不好对付，不过我从浮定那里得知了它的特性。其核心控制着整个集体，所以它用藤蔓层层环绕保护核心。藤蔓表层以灵质作为防护，藤芯以魂质作为神经。如果遭受猛烈攻击，它会先后退，等敌人追击后再弹出更多藤蔓缠绕对方。另外，它是可以移动的，如果一块地区的灵质枯竭，它就会整体进行迁移。

那么如何达到我的目的呢？我退到它的探测范围之外，然后飞向高空。到达十二千米左右高度，这里的魂质已经足够浓郁，我借助空中的魂质，朝藤沼相反的斜上方架设加速轨道。加速轨道由圆环构成，不需要相连，也不需要耐用，我很快铺了一千米。站在轨道的顶端，此处的魂压并没有之前预估的大，那种危险的感觉也只是稍有增加。

我高高一跃，塑形出适合在轨道上行动的魂质触手，然后用力推动自身，在空中完成最初的加速，然后才接触轨道。在轨道上，我的速度不断增加，很快就超过了我八百米每秒的巡航速度，然后是两倍，三倍，四倍，五倍，最终达到六倍速度，也就是约四千八百米每秒。

越过最后几个轨道环，它们在我身后破碎开来，缓缓消散。我进入了藤沼的视野之中。藤蔓涌动，在一秒内就开始朝我这个方向调集藤蔓。那些藤蔓收起叶子，尖端暴突，形成一个个气球。那并不是防御，而是——

轰！灵质剧烈爆炸。在我接近那些气球之后，它们批量炸开，腐蚀性的汁液四溅（对容灵残躯无效），藤蔓使用坚硬叶片抵挡，然后被藤蔓摇荡着化解对它自己的冲击。

这些抵抗使我受到了一定的阻力，但是我还是冲入了藤蔓深处，距离藤沼核心仅有百米距离。这里的藤蔓直径足有一米，几乎没有间距，将我阻挡下来。不过，这个距离已经够了，我对藤沼核心发动：灵魂融合术。

原本紧紧包裹在核心周围的藤蔓顿时被我控制，核心失去了来自藤蔓的力量，挣扎的速度都变慢了。稍作观察后，我用灵魂融合术直接接触藤沼核心的魂体，它已经被压制，没有进行反抗。就这样，我缓缓渗透它的本能，使之和我的魂体紧密相连。
