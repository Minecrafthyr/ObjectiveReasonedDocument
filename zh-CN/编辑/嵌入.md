## 使用方法

所有可用的嵌入前缀组合：

```md
![[嵌入#示例]]

full![[嵌入#示例]]  
content![[嵌入#示例]]  
card![[嵌入#示例]]  
inline![[嵌入#示例]]

full-card![[嵌入#示例]]  
full-inline![[嵌入#示例]]  
content-card![[嵌入#示例]]  
content-inline![[嵌入#示例]]
```

| 内容                                    | 样式                   |
| --------------------------------------- | ---------------------- |
| full<br>所有内容                        | card<br>用卡片包裹输出 |
| content<br>不包括标题或段落标题前的内容 | inline<br>内联         |

内容和样式可以混合或单独使用。可以在[settings.json](/.vscode/settings.json)中更改默认的嵌入前缀。
